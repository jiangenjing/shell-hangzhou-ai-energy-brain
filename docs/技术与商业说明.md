# 技术与商业说明

## 1. 决策目标

项目将用户体验、场站经营和电网约束放在同一个决策框架中。对候选站点 \(s\)，定义广义补能成本：

\[
C_s = \alpha T_{travel} + \beta E(T_{wait}) + \gamma T_{charge} + \delta Cost + \lambda P(failure) + \mu CO_2
\]

其中权重由用户偏好与场景动态调整。时间敏感用户提高 \(\alpha,\beta,\gamma\)，价格敏感用户提高 \(\delta\)，可靠性敏感用户提高 \(\lambda\)。系统推荐广义成本最低的站点，并提供置信区间和备选方案。

## 2. 需求与排队预测

- 输入：历史订单、到站时间、天气、节假日、道路状态、站点价格、附近活动与实时枪位状态。
- 输出：未来 15–60 分钟到站需求、枪位释放时间、P50/P90 等待时间和到站可启动概率。
- 方法：梯度提升树或时序模型完成需求预测，结合离散事件仿真或排队模型估计等待分布，再做置信度校准。
- 评估：时间滚动验证，使用 MAE/WAPE、等待时间校准误差及真实到站成功率，避免随机切分造成信息泄漏。

## 3. 充电功率调度

以 15 分钟为滚动窗口，在配变容量、枪机上限、车辆受电曲线和离站需求约束下优化：

\[
\min \sum_t p_t \sum_i x_{i,t}\Delta t
+ \lambda_1 P_{peak}
+ \lambda_2 \sum_i u_i
+ \lambda_3 \sum_{i,t}|x_{i,t}-x_{i,t-1}|
\]

约束包括：

- \(0 \le x_{i,t} \le \min(P_i^{vehicle},P_i^{charger})\)
- \(\sum_i x_{i,t} \le P_t^{transformer}\)
- \(\sum_t \eta_i x_{i,t}\Delta t + u_i \ge E_i^{target}\)

其中 \(u_i\) 表示离站时未满足的电量需求并施加高额惩罚。任何通信异常或安全边界触发时，系统回退至设备本地控制策略。

## 4. 预测运维

- 以枪级通信、电流、电压、温度、启动失败、历史故障码和工单作为特征。
- 输出未来故障概率、异常类型和建议检查项。
- 高置信异常枪在推荐排序中降权；超过阈值时自动生成工单，但保留人工审批与审计记录。
- 评估不只看 AUC，还关注提前量、误报工时、故障停机时长和由此挽回的订单毛利。

## 5. 因果增量权益

对用户 \(i\) 估计权益带来的个体增量：

\[
\tau_i = E(Y \mid T=1,x_i) - E(Y \mid T=0,x_i)
\]

仅当：

\[
\tau_i \times 未来贡献毛利 > 权益成本 + 触达成本
\]

才进行投放。模型通过随机对照、同类型站点配对或分阶段上线验证，避免把自然复充误判为营销效果。

## 6. 商业模式

价值主张：为杭州壳牌充电业务运营方，在站点利用率不均、故障停机和通用补贴侵蚀利润的场景下，通过 AI 智选、功率优化、预测运维与因果权益，提升单站年度经营贡献。

- **唯一计费单位**：站。
- **直营站**：壳牌保留经实验核验的全部增量利润。
- **合作站**：2.4 万元/站·年基础服务费，加 20% 经核验增量经营贡献，按季结算。
- **合同设计**：三年框架协议，前六个月试点；未通过安全与财务闸门可退出。
- **额外收入**：VPP、需求响应、绿证等仅按真实结算另行分成，不把政策补贴作为基准盈利的必要条件。

## 7. 数据与财务边界

- 演示中的站点、等待、功率、收益和减排数字用于说明交互与计算逻辑，不代表真实运营数据。
- 单站基准与改善幅度属于团队测算场景，正式商业决策需使用脱敏交易、设备、会员、工单与损益数据重新标定。
- 碳账单按订单电量与分时排放因子核算，用于用户提示和企业报告，不直接宣称为可交易碳资产。
